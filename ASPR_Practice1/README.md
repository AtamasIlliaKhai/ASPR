## Практична робота №7

Тема: сіткове планування. Метод критичного шляху.

Мета роботи: розрахувати параметри сіткового графіка проєкту, знайти критичний шлях, визначити тривалість проєкту, побудувати календарний план робіт і графік завантаження ресурсів.

У програмі реалізовано:
розрахунок ранніх початків і ранніх завершень робіт;
розрахунок пізніх початків і пізніх завершень робіт;
обчислення резервів часу;
визначення критичних робіт;
пошук критичного шляху;
обчислення тривалості проєкту;
побудову початкового календарного плану;
побудову графіка завантаження людських ресурсів;
оптимізацію календарного плану за піковим навантаженням;
формування текстової діаграми Ганта.

Основні класи:
`ProjectTask` зберігає дані однієї роботи проєкту.
`NetworkPlanningInput` зберігає перелік робіт і опис задачі.
`NetworkPlanningSolver` виконує розрахунок сіткового графіка.
`NetworkPlanningResult` зберігає тривалість проєкту, критичний шлях, календарний план і графік завантаження ресурсів.

Пункти меню:
27 - розв'язати задачу сіткового планування вручну.
28 - виконати тестову задачу сіткового планування.
29 - виконати власний варіант для практичної роботи 7.
