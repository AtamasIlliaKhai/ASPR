# ASPR Practice 4

Репозиторій містить консольну програму мовою C# для виконання практичної роботи з дисципліни «Алгоритми систем підтримки прийняття рішень».

## Практична робота №4

Тема роботи: ігри з природою.

Мета роботи: навчитися знаходити оптимальні стратегії гравця в іграх з природою за допомогою основних критеріїв прийняття рішень в умовах невизначеності та ризику.

У практичній роботі реалізовано програму, яка для заданої матриці корисності `U` визначає оптимальні стратегії за такими критеріями:

- критерій Вальда;
- критерій оптимізму;
- критерій Гурвіца;
- критерій Севіджа;
- критерій Байєса;
- критерій Лапласа.

## Суть роботи програми

Програма приймає матрицю корисності, у якій рядки відповідають стратегіям гравця, а стовпці відповідають можливим станам природи.

Для кожної стратегії програма виконує розрахунок за всіма критеріями.

За критерієм Вальда для кожної стратегії знаходиться мінімальний виграш, після чого обирається стратегія з найбільшим мінімальним виграшем.

За критерієм оптимізму для кожної стратегії знаходиться максимальний виграш, після чого обирається стратегія з найбільшим максимальним виграшем.

За критерієм Гурвіца використовується коефіцієнт оптимізму `alpha`. Для кожної стратегії обчислюється зважена оцінка між найкращим і найгіршим результатом.

Формула критерію Гурвіца:

H_i = alpha * max(A_i) + (1 - alpha) * min(A_i)

За критерієм Севіджа будується матриця ризиків. Для кожного стану природи знаходиться найкращий виграш, після чого кожен елемент стовпця віднімається від цього максимуму. Далі для кожної стратегії визначається максимальний ризик, а оптимальною вважається стратегія з мінімальним максимальним ризиком.

За критерієм Байєса використовуються задані ймовірності станів природи. Для кожної стратегії обчислюється математичне сподівання виграшу.

За критерієм Лапласа всі стани природи вважаються рівноймовірними, тому для кожної стратегії обчислюється середнє арифметичне виграшів.

## Реалізовані класи

`Program` відповідає за меню програми, запуск практичних робіт, введення даних і виведення результатів.

`NatureGameInput` зберігає вхідні дані гри з природою: матрицю корисності, коефіцієнт оптимізму для критерію Гурвіца, ймовірності станів природи та текстовий опис задачі.

`MatrixGameSolver` виконує розрахунок гри з природою за критеріями Вальда, оптимізму, Гурвіца, Севіджа, Байєса та Лапласа.

`NatureGameResult` зберігає результати розрахунку за кожним критерієм, включно з оптимальними стратегіями, матрицею ризиків, значеннями критеріїв та допоміжними проміжними даними.

`ReportBuilder` формує текстовий протокол розрахунку.

## Перевірка результатів

Результати роботи програми можна перевірити за допомогою Excel.

Для цього створюється таблиця з матрицею корисності, після чого формулами `MIN`, `MAX`, `SUMPRODUCT` і `AVERAGE` обчислюються значення критеріїв Вальда, оптимізму, Гурвіца, Байєса та Лапласа.

Excel у цій роботі використовується не через Solver, а як контрольна таблиця з формулами.
