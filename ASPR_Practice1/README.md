# ASPR Practice 1

Репозиторій містить консольну програму мовою C# для виконання практичних робіт з дисципліни «Алгоритми систем підтримки прийняття рішень».

## Практична робота 1A

Тема: застосування звичайних жорданових виключень.

У цій частині реалізовано пошук оберненої матриці, обчислення рангу матриці та розв'язання системи лінійних алгебраїчних рівнянь методом Гауса з використанням звичайних жорданових виключень.

## Практична робота 1B

Тема: розв'язання задачі лінійного програмування із системою обмежень у вигляді нерівностей.

У цій частині реалізовано пошук опорного розв'язку та пошук оптимального розв'язку задачі лінійного програмування за допомогою модифікованих жорданових виключень.

## Практична робота 1C

Тема: розв'язання задачі лінійного програмування зі змішаною системою обмежень.

У цій частині програму розширено для роботи зі змішаною системою обмежень. Реалізовано видалення нуль-рядків у симплекс-таблиці, пошук опорного розв'язку та пошук оптимального розв'язку задачі лінійного програмування.

## Практична робота 1D

Тема: розв'язання задачі цілочислового лінійного програмування методом Гоморі.

Мета роботи: з використанням методу Гоморі розв'язати задачу цілочислового лінійного програмування.

За основу взято програму з попередніх практичних робіт, у яких було реалізовано симплекс-метод на основі модифікованих жорданових виключень. У практичній роботі 1D до програми додано механізм отримання цілочислового розв'язку.

Програма спочатку знаходить оптимальний розв'язок задачі лінійного програмування без урахування цілочисловості. Після цього перевіряється, чи всі компоненти вектора X є цілими. Якщо всі змінні цілі, метод Гоморі завершує роботу. Якщо серед базисних змінних є дробові значення, програма знаходить рядок із дробовим вільним членом, будує додаткове обмеження Гоморі, додає його до симплекс-таблиці та повторно виконує пошук опорного й оптимального розв'язку.

У роботі реалізовано такі можливості:

- розв'язання задачі лінійного програмування симплекс-методом;
- перевірка цілочисловості знайденого розв'язку;
- вибір рядка для побудови відсікання Гоморі;
- обчислення дробових частин коефіцієнтів;
- побудова нового обмеження Гоморі;
- додавання нового рядка до симплекс-таблиці;
- повторне розв'язання задачі після додавання відсікання;
- отримання цілочислового оптимального розв'язку.

## Основні класи

`Program` відповідає за меню програми, запуск окремих практичних робіт, введення даних і виведення результатів.

`Matrix` реалізує збереження та базову обробку матриць.

`JordanSolver` реалізує звичайні жорданові виключення, пошук оберненої матриці, рангу та розв'язання СЛАР.

`SimplexTable` зберігає симплекс-таблицю, виконує модифіковані жорданові виключення, видалення стовпців і додавання нових рядків.

`SimplexSolver` реалізує видалення нуль-рядків, пошук опорного розв'язку та пошук оптимального розв'язку.

`LinearProgrammingProblem` зберігає постановку задачі лінійного програмування, коефіцієнти цільової функції, обмеження та готові рядки симплекс-таблиці для вбудованих варіантів.

`SimplexResult` зберігає знайдений вектор X, значення цільової функції Z та інформацію про стан розв'язку.

`SimplexFullResult` зберігає результат симплекс-методу разом із фінальною симплекс-таблицею.

`GomorySolver` реалізує метод Гоморі для отримання цілочислового розв'язку.

`GomoryResult` зберігає фінальний цілочисловий результат, фінальну симплекс-таблицю та кількість доданих відсікань Гоморі.

`ReportBuilder` формує текстовий протокол обчислень.

## Варіант

Виконується варіант 3.

Для практичної роботи 1D використовується задача:

Z = 3x1 + x2 + x3 - x4 -> max

при обмеженнях:

-x1 + x2 + x3 + x4 <= 2

x1 - x2 + x3 + x4 >= 2

x1 + x2 - x3 + x4 <= 2

x1 + x2 + x3 - x4 <= 2

xj >= 0

xj - цілі

## Запуск програми

Програма запускається як консольний застосунок C#.

Після запуску користувач обирає потрібний пункт меню.

Для практичної роботи 1D використовуються такі пункти:

15 - розв'язати задачу цілочислового лінійного програмування методом Гоморі з ручним введенням даних.

16 - виконати власний варіант 3 для роботи 1D.

17 - виконати тестовий приклад для методу Гоморі.

## Перевірка роботи

Для перевірки методу Гоморі використовується тестова задача:

Z = x1 + x2 -> max

при обмеженнях:

2x1 + x2 <= 4

x1 + 2x2 <= 4

xj >= 0

xj - цілі

Звичайний симплекс-метод для цієї задачі дає дробовий оптимальний розв'язок, тому програма повинна побудувати відсікання Гоморі та отримати цілочисловий оптимальний розв'язок.

Очікуване оптимальне значення цільової функції для тестового прикладу:

Zmax = 2

Можливі оптимальні цілочислові розв'язки:

X = (2; 0)

X = (1; 1)

X = (0; 2)

Для власного варіанту 3 програма повинна вивести оптимальний цілочисловий розв'язок, фінальну симплекс-таблицю, кількість доданих відсікань Гоморі та повний протокол розрахунку.
