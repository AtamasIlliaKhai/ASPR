# ASPR Practice 1

Практична робота №1 з дисципліни «Алгоритми систем підтримки прийняття рішень».

Тема: застосування звичайних жорданових виключень.

Реалізовано:
- пошук оберненої матриці;
- обчислення рангу матриці;
- розв'язання системи лінійних алгебраїчних рівнянь методом Гауса.

Мова програмування: C#.
Варіант: 3.
