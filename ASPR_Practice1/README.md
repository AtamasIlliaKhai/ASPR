## Практична робота №5

Тема: транспортна задача.

Мета роботи: навчитися розв'язувати транспортну задачу, визначати її тип, будувати початкові опорні плани та знаходити оптимальний план перевезень.

У програмі реалізовано:
метод північно-західного кута;
метод мінімального елемента;
метод потенціалів;
визначення типу транспортної задачі;
приведення відкритої транспортної задачі до закритої;
обчислення загальної вартості плану перевезень;
формування протоколу розрахунку.

Основні класи:
`TransportInput` зберігає матрицю вартостей, запаси постачальників, потреби споживачів і опис задачі.
`TransportSolution` зберігає транспортний план, базисні клітинки, потенціали, оцінки та загальну вартість.
`TransportSolver` реалізує метод північно-західного кута, метод мінімального елемента та метод потенціалів.

Пункти меню:
21 - розв'язати транспортну задачу вручну.
22 - виконати тестову транспортну задачу.
23 - виконати власний варіант 3 для практичної роботи 5.
