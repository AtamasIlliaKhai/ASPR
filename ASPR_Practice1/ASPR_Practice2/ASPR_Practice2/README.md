# ASPR Practice 2

Практична робота №2 з дисципліни «Алгоритми систем підтримки прийняття рішень».

## Тема роботи

Розв'язання задачі лінійного програмування з системою обмежень у вигляді нерівностей за допомогою симплекс-методу та модифікованих жорданових виключень.

## Мета роботи

Мета роботи — розв'язати з використанням симплекс-методу задачу лінійного програмування із системою обмежень у вигляді нерівностей.

Під час виконання роботи розроблено консольну програму мовою C#, у якій на основі модифікованих жорданових виключень реалізовано пошук опорного розв'язку задачі лінійного програмування та пошук оптимального розв'язку задачі лінійного програмування.

## Мова та середовище розробки

Мова програмування: C#.

Тип застосунку: Console App.

Середовище розробки: Microsoft Visual Studio.

Платформа: .NET Framework.

## Реалізований функціонал

Програма дозволяє розв'язувати задачі лінійного програмування з обмеженнями типу `<=`, `>=` та `=`.

У програмі реалізовано введення задачі вручну, запуск тестових прикладів, запуск власного варіанту 3, побудову початкової симплекс-таблиці, пошук опорного розв'язку, пошук оптимального розв'язку, виконання модифікованих жорданових виключень, перевірку необмеженості функції мети, перевірку суперечливості системи обмежень і формування текстового протоколу розрахунку.

## Основні класи програми

`Program` відповідає за меню програми, введення даних користувачем, запуск тестових задач і виведення результатів.

`LinearProgrammingProblem` зберігає математичну постановку задачі: матрицю коефіцієнтів обмежень, знаки обмежень, праві частини, коефіцієнти функції мети, тип оптимізації та опис задачі.

`SimplexTableau` зберігає симплекс-таблицю, базисні змінні, рядок оцінок, вільні члени, назви змінних і ознаки штучних змінних.

`ModifiedJordanSimplexSolver` виконує розв'язання задачі симплекс-методом на основі модифікованих жорданових виключень.

`SimplexResult` зберігає результат розв'язання: значення змінних, значення функції мети та ознаки оптимальності, необмеженості або суперечливості задачі.

`ReportBuilder` формує текстовий протокол розрахунку.
