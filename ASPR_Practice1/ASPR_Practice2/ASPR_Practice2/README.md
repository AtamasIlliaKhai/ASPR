# ASPR Practice 2

Практична робота №2 з дисципліни «Алгоритми систем підтримки прийняття рішень».

## Тема роботи

Побудова й розв'язання двоїстої задачі лінійного програмування за допомогою симплекс-методу та графічного методу.

## Мета роботи

Мета роботи — побудувати й розв'язати з допомогою симплекс-методу та графічного методу двоїсту задачу лінійного програмування.

Під час виконання роботи розроблено консольну програму мовою C#, яка дозволяє побудувати для задачі лінійного програмування пряму задачу Z та відповідну їй двоїсту задачу W, розв'язати пару взаємно двоїстих задач симплекс-методом, порівняти значення цільових функцій прямої та двоїстої задач, а також виконати графічне розв'язання задачі з двома змінними.

## Мова та середовище розробки

Мова програмування: C#.

Тип застосунку: Console App.

Середовище розробки: Microsoft Visual Studio.

Платформа: .NET Framework.
